Data Flow — Filter to Response

Step 1
User Selects Filter
FilterBar updates useFilters() singleton refs (period, location, category, status)
›
Step 2
Watcher Fires
Each view watches filter refs; calls loadData() on any change
›
Step 3
API Call
getCurrentFilters() builds query params; axios GET to /api/endpoint
›
Step 4
Backend Filters
apply_filters() → filter_by_month() applied in sequence; returns JSON array
›
Step 5
Reactive Update
Response stored in refs; computed properties recalculate; template re-renders

Filter System — useFilters.js

UI Label State Ref API Param Values
Time Period selectedPeriod month all · 2025-01…2025-12 · Q1-2025…Q4-2025
Location selectedLocation warehouse all · San Francisco · London · Tokyo
Category selectedCategory category all · circuit boards · sensors · actuators · controllers · power supplies
Order Status selectedStatus status all · delivered · shipped · processing · backordered

Refs are declared at module scope (outside the export function) — this is the singleton pattern. All views share the same ref instances, so a filter change in one view instantly affects all others.
